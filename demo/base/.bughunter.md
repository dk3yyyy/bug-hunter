# 🎃 Bug Hunter rules for haunted-candy-shop

## Always check
- All database access must use parameterized queries. Never build SQL with string interpolation.
- Every route handler that reads `req.body` or `req.query` must validate input before using it.
- Async functions from `src/costumes.ts` must always be awaited.

## Conventions we accept (don't flag)
- `console.log` is fine in this demo project.
- We don't require JSDoc comments.

## Extra attention
- Anything touching `/treat` or candy totals: check for division by zero and empty arrays.
